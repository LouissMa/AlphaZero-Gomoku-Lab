# Support

## Using the project

Start with the [English README](README.md) or
[Chinese README](README.zh-CN.md), then run:

```bash
python -m alphazero_gomoku doctor
```

The guides under [`docs/`](docs/) cover training, scalable self-play, evaluation,
Gumbel AlphaZero, the web application, and releases. Search existing GitHub
issues before opening a new one.

## Where to ask

- Reproducible defects: use the **Bug report** issue form.
- Scoped enhancements: use the **Feature request** issue form.
- Setup and usage questions: open a GitHub issue with the `question` label and
  include the doctor output, operating system, Python version, install command,
  and the smallest command that reproduces the problem.
- Vulnerabilities: follow [SECURITY.md](SECURITY.md); never report them publicly.

Support is community-provided on a best-effort basis. There is no guaranteed
response time, service-level agreement, private consulting, or guarantee that a
large training workload will fit a particular machine.
